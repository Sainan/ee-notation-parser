# EE Notation Parser

Converts the format internally used by Warframe's engine — the Evolution Engine — into JSON.

## Usage

This header-only library is designed to be included alongside [Soup](https://github.com/calamity-inc/Soup).

## CLI Tools

- [ee2json](ee2json)
- [json2ee](json2ee)
- [bin2json](bin2json)
